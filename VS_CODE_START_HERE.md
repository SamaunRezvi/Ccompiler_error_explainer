# VS Code Start Guide

1. Extract the project ZIP.
2. Open the extracted folder in VS Code.
3. Install the recommended Microsoft C/C++ extension.
4. Open `playground/user_code.c`.
5. Press `Ctrl+Shift+B`.

The default playground file intentionally contains a missing semicolon. The project should compile the explainer itself successfully and then explain the error in the playground program.

To analyze another C file, open that file and run:

```text
Terminal > Run Task > 4. Analyze Current C File
```

To run all sample tests:

```text
Terminal > Run Task > 5. Run Project Tests
```
